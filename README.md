## About me

I'm **Karthikeyan Prabhu**, a Senior Frontend Developer from Coimbatore, India, with 5+ years of experience building responsive and accessible web and mobile products. I specialize in **React, Next.js, TypeScript, Angular, and Ionic**, with a strong focus on reusable component architecture, performance, and design-system consistency.

I also build solutions across the Microsoft ecosystem using **SPFx, SharePoint Online, Fluent UI, Power Apps, Power Automate, Copilot Studio, and Dataverse**.

- ⚡ Improved product performance with memoization, virtualization, and code splitting
- 🧩 Built reusable component libraries for dashboards, CRM modules, and learning platforms
- ♿ Improved keyboard navigation, color contrast, and responsive workflows
- 🔌 Integrated REST APIs, Microsoft Graph, Axios, and Fetch
- 🤝 Experienced in Agile delivery with design, backend, and QA teams
